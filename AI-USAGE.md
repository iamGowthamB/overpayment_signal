# AI Usage

AI tools were used as a supplementary development assistant during the project.

### AI-Assisted Work

AI assistance was mainly used for:

- Clarifying implementation issues and technical concepts
- Providing code suggestions when needed
- Debugging assistance when errors were encountered
- Minor code refinement and documentation support

### AI-Assisted Development Approach

AI was used as a supporting coding and debugging tool rather than as the sole developer.

The development process followed:

**Planning → Implementation → Testing → Analysis → Modification → Validation**

AI assistance was used when needed during implementation, debugging, or
technical clarification. Code was also manually implemented, modified, and
debugged during development.
