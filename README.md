# The Overpayment Signal
ML-based system to prioritize the 20 benefit-payment cases most worth reviewing.

## Objective

* Rank cases by investigation priority.
* Explain why each case was selected.
* Analyze model behavior across population groups.

## Approach

Data → Preprocessing → ML → Risk Score → Top 20
                         ↓
                  Explainability
                         ↓
                  Fairness Analysis
